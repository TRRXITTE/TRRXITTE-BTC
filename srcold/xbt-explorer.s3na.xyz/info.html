Bitcoin Classic Public API

A listing of public API endpoints for retrieving Bitcoin Classic coin data from the network without the need for a local wallet
API Documentation

API Calls

Return data from coind

  • getdifficulty
    Returns the current difficulty.
    xbt-explorer.s3na.xyz/api/getdifficulty

  • getconnectioncount
    Returns the number of connections the block explorer has to other nodes.
    xbt-explorer.s3na.xyz/api/getconnectioncount

  • getblockcount
    Returns the current block index.
    xbt-explorer.s3na.xyz/api/getblockcount

  • getblockhash [index]
    Returns the hash of the block at [index]; index 0 is the genesis block.
    xbt-explorer.s3na.xyz/api/getblockhash?index=64152

  • getblock [hash]
    Returns information about the block with the given hash.
    xbt-explorer.s3na.xyz/api/getblock?hash=f58cf5e9645f407522e4af9af2b3a6bcf506c91d29db29515f0c6bcbb2cf88e3

  • getrawtransaction [txid] [decrypt]
    Returns raw transaction representation for given transaction id. decrypt can be set to 0(false) or 1(true).
    xbt-explorer.s3na.xyz/api/getrawtransaction?txid=b3fff0a01351cfa01ab8ec2c384adb67dca74a98a5665bef1600b87f9ba5f617&decrypt=0
    xbt-explorer.s3na.xyz/api/getrawtransaction?txid=b3fff0a01351cfa01ab8ec2c384adb67dca74a98a5665bef1600b87f9ba5f617&decrypt=1

  • getnetworkhashps
    Returns the current network hashrate. (hash/s)
    xbt-explorer.s3na.xyz/api/getnetworkhashps

  • getvotelist
    Returns the current vote list.
    xbt-explorer.s3na.xyz/api/getvotelist

Extended API

Return data from local indexes

  • getmoneysupply
    Returns current money supply
    xbt-explorer.s3na.xyz/ext/getmoneysupply

  • getdistribution
    Returns wealth distribution stats
    xbt-explorer.s3na.xyz/ext/getdistribution

  • getaddress (/ext/getaddress/hash)
    Returns information for given address
    xbt-explorer.s3na.xyz/ext/getaddress/7XmamKonvce9CXdpynoavP7Yj2VCFBpJ8o

  • getaddresstxs (/ext/getaddresstxs/hash/start/length)
    Returns last [length] transactions for address [hash], starting from offset [start]
    xbt-explorer.s3na.xyz/ext/getaddresstxs/7XmamKonvce9CXdpynoavP7Yj2VCFBpJ8o/0/50

  • gettx (/ext/gettx/hash)
    Returns information for given tx hash
    xbt-explorer.s3na.xyz/ext/gettx/b3fff0a01351cfa01ab8ec2c384adb67dca74a98a5665bef1600b87f9ba5f617

  • getbalance (/ext/getbalance/hash)
    Returns current balance of given address
    xbt-explorer.s3na.xyz/ext/getbalance/7XmamKonvce9CXdpynoavP7Yj2VCFBpJ8o

  • getlasttxs (/ext/getlasttxs/min/start/length)
    Returns last [length] transactions greater than [min] coins, starting from offset [start]
    Note: [length] is limited to returning 100 records per query
    xbt-explorer.s3na.xyz/ext/getlasttxs/100/0/100

  • getcurrentprice
    Returns last known exchange price
    xbt-explorer.s3na.xyz/ext/getcurrentprice

  • getnetworkpeers
    Returns the list of network peers that have connected to the explorer node in the last 24 hours
    xbt-explorer.s3na.xyz/ext/getnetworkpeers

  • getbasicstats
    Returns basic statistics about the coin including: block count, circulating supply, USD price, USDT price
    xbt-explorer.s3na.xyz/ext/getbasicstats

  • getsummary
    Returns a summary of coin data including: difficulty, hybrid difficulty, circulating supply, hash rate, USDT price, USD price, network connection count, block count
    xbt-explorer.s3na.xyz/ext/getsummary
